## Summary

ARCD(Anatomical Region-Guided Contrastive Decoding)는 해부학적 영역의 분할 마스크를 의료 VLM의 시각 토큰 단위 마스크로 바꾸고, 그 영역을 지운 branch와 강조한 branch를 token·attention·logit 세 단계에서 가중 결합해 답을 생성하는 학습 없는(training-free) 디코딩 전략이다. 저자들은 Phi-3.5V 기반 의료 VLM에 적용해 흉부 X-ray, 복부 CT, 뇌 MRI, 안구 B-scan 초음파 VQA에서 정확도 향상과 환각 감소를 보고한다.

- **기여 1. 해부학 영역 기반 3단계 대조 디코딩**
  - 지정한 해부학 영역을 기준으로 token, attention, logit 세 단계에서 생성을 유도해 시각적 근거(visual grounding)를 강화하는 디코딩 전략

- **기여 2. 학습 없는 plug-and-play 구성**
  - 파라미터 갱신 없이 여러 VLM과 분할 모델에 결합할 수 있는 구조

- **기여 3. 네 가지 의료 영상 모달리티에서의 검증**
  - 흉부 X-ray, CT, 뇌 MRI, 안구 B-scan 초음파 데이터셋에서의 효과와 일반화 실험

## Background

의료 VLM(Medical Vision-Language Model)은 판독문 자동 생성과 시각 질의응답(VQA)에서 가능성을 보였지만, 시각 증거와 모순되는 그럴듯한 문장을 만드는 환각(hallucination) 때문에 임상 신뢰성이 떨어진다. 저자들은 원인을 시각적 근거의 부족으로 본다. 모델이 이미지 내용보다 학습 데이터의 통계적 편향과 텍스트 사전지식(prior)을 우선한다는 것이다. 예를 들어 학습 판독문에는 PICC line이 자주 등장하고 모양이 비슷한 ECG lead는 드물게 언급되므로, 모델은 이미지에 보이는 ECG lead를 PICC line으로 답한다. 저자들이 던지는 질문은 의사가 판독하듯 모델의 어텐션(attention)을 진단적으로 관련된 특정 영역에 확실히 두게 할 방법이다.

- **① 의료 특화 VLM 적응 (LLaVA-Med, HuatuoGPT-Vision, RadFM, Quilt-LLaVA, MM-Skin)**
  - **방식**: 의료 이미지-텍스트 데이터로 일반 VLM을 instruction tuning하거나 모달리티별 전용 모델 구축
  - **한계**: 텍스트 정확도는 올랐지만 생성 문장을 진단적으로 관련된 이미지 영역에 명시적으로 연결하는 세밀한 시각적 근거 부족

- **② 학습 기반 환각 완화 (MMedPO, R-LLaVA, ShareGPT4V, HA-DPO, PerturboLLaVA)**
  - **방식**: 선호 최적화, 관심 영역(ROI) 약한 주석 결합, 데이터 보강, 적대적 학습으로 모델 자체를 교정
  - **한계**: 의료 데이터 주석에 드는 높은 비용과 전문성 때문에 확장성 제한

- **③ 학습 없는 추론 시 개입 (VCD, ICD, Woodpecker, Hyper-RAG)**
  - **방식**: 원본과 왜곡 입력의 출력 대비, 검색 증강, 사후 교정으로 추론 단계에서 환각 억제
  - **한계**: 전역적이고 대상을 가리지 않는 교정이라 복잡한 임상 데이터에서 효과가 불안정하고 해석 가능성 부족. VCD는 원본 branch에 환각을 유발하는 불필요한 시각 정보가 그대로 남고, logit 단계의 사후 개입이라 어텐션 계산 단계에서 엉뚱한 영역에 쏠린 초점을 고치지 못함

세 계열은 모두 모델이 이미지의 어느 영역을 근거로 답하는지를 직접 다루지 않는다. 의료 적응 모델은 지식을 넣을 뿐 근거 영역을 강제하지 않고, 학습 기반 교정은 영역 수준의 주석 비용에 막히며, 추론 시 개입은 이미지 전체에 일괄적으로 작용해 특정 해부 구조에 초점을 두지 못한다. 저자들은 비용이 큰 재학습 없이 모델의 어텐션이 진단적으로 관련된 영역에 놓이도록 보장하는 수단이 없다는 점을 문제로 제기한다.

## Method

ARCD의 핵심은 같은 입력을 두 갈래로 흘려 비교하는 것이다. 한 갈래(guided)는 지정한 해부학 영역의 시각 토큰에 어텐션을 더 준다. 다른 갈래는 논문이 "original (unguided)"라고 부르지만 원본 입력 그대로가 아니다. 지정 영역의 토큰 임베딩을 거의 0으로 줄여, 그 영역의 정보가 빠진 상태로 답을 만든다. 다음 토큰을 고를 때 두 갈래의 로그확률을 guided 쪽으로 외삽해 결합하면, 영역 정보가 있을 때 확률이 올라가는 토큰은 더 강해지고 영역을 지워도 똑같이 나오는 토큰은 상대적으로 약해진다. 저자들은 이 방식으로 지정 영역의 시각 근거에 기댄 답을 강화하고 사실과 어긋난 출력을 억제한다고 설명한다. VCD가 노이즈를 섞은 이미지 전체를 대비 대상으로 쓰는 것과 달리, ARCD의 대비 대상은 "그 영역만 지운 입력"이다. 영역 정보는 전문가 주석이나 PSPNet·MedSAM 같은 사전학습 분할 모델에서 얻는다.

이 구성은 Background의 한계에 각각 대응한다. 세밀한 시각적 근거가 부족하다는 문제(①)에는 분할 마스크를 시각 토큰 위치에 맞춘 마스크로 바꿔 생성의 근거 영역을 명시적으로 지정하는 것으로 답한다. 주석 비용(②)에는 파라미터 갱신 없이 추론 시에만 작동하는 구조로 대응한다. 전역적이고 대상을 가리지 않는 교정(③)에는 영역 단위 대비로, VCD의 원본 branch에 남는 불필요한 시각 정보에는 token 단계의 영역 억제로, logit 단계 사후 개입의 한계에는 attention 단계 개입을 추가하는 것으로 대응한다.

### Task Formulation and Baseline

VLM은 이미지 $\mathcal{V}$와 질문 $\mathcal{Q}$가 주어지면 답 $$\mathcal{Y} = \{y_1, \dots, y_T\}$$를 자기회귀(auto-regressive) 방식으로 생성한다.

$$
\log P_\theta(\mathcal{Y} \mid \mathcal{V}, \mathcal{Q}) = \sum_{t=1}^{T} \log P_\theta(y_t \mid \mathcal{V}, \mathcal{Q}, y_{<t})
$$

저자들은 Phi-3.5 Vision이 일반 시각 이해력은 좋지만 의료 지식이 부족해 뚜렷한 병변도 놓친다고 보고, PubMedVision 데이터로 LoRA fine-tuning한 Phi3.5V-Med를 모든 실험의 기준 모델로 삼는다. 이 모델을 zero-shot 기준으로 쓰고, 각 downstream 데이터셋에 한 번 더 fine-tuning한 모델을 fine-tuning 기준으로 쓴다. ARCD는 두 기준 모델 위에 디코딩 전략으로만 얹힌다.

### Dynamic Attention Mask Generation

저자들은 fine-tuning만으로는 응답이 실제 시각 증거에 근거한다고 보장할 수 없다고 보고, 먼저 픽셀 단위 분할 마스크 $$\mathcal{S} \in \{0,1\}^{H \times W}$$(관심 영역이 1)를 VLM의 시각 토큰 순서와 정확히 맞는 1차원 마스크로 바꾼다. 이 변환이 필요한 이유는 Phi-3.5V가 이미지를 한 장의 격자가 아니라 여러 국소 뷰와 전역 뷰, 행마다 붙는 줄바꿈 토큰으로 펼쳐 넣기 때문이다.

Phi-3.5V의 ViT-L/14는 336×336 이미지를 24×24 patch로 나누고, 이를 12×12 특징 격자로 바꾼다($L=12$). 전역 마스크 $\mathcal{M}_g$는 $\mathcal{S}$를 $L \times L$로 다운샘플링하고 각 행 끝에 줄바꿈 구분자(값 0)를 붙여 길이 $L \times (L+1)$로 펼친 것이다. 국소 마스크 $\mathcal{M}_l$은 이미지를 $G_h \times G_w$개의 국소 뷰로 나눈 구성에 맞춰 $\mathcal{S}$를 $(G_h \cdot L) \times (G_w \cdot L + 1)$ 격자로 다운샘플링하고 같은 방식으로 펼친다. $G = (G_h, G_w)$는 사용자가 정하며, 클수록 작은 부분에 초점을 둘 수 있다. Figure 2에서 다운샘플링은 max-pooling이다. 최종 마스크는 $$\mathcal{M} = [\mathcal{M}_l; m_{sep}; \mathcal{M}_g]$$이고 전체 길이는 다음과 같다.

$$
N = G_h \cdot L \cdot (G_w \cdot L + 1) + 1 + L \cdot (L + 1)
$$

### Mask-Guided Conditional Token Weighting

저자들은 VCD를 여러 단계로 확장한다고 설명한다. 마스크 $$\mathcal{M} = \{m_1, m_2, \dots\}$$에서 $m_i=1$인 토큰이 초점을 강화할 영역이다. 이미지와 질문을 인코딩한 임베딩을 $\mathbf{c} = f(\mathbf{x})$라 할 때, 먼저 token 단계에서 unguided branch $\bar{\mathbf{c}}$의 영역 토큰 임베딩을 작은 가중치 $\alpha$(예: 0.01)로 줄인다.

$$
\bar{c}_i =
\begin{cases}
\alpha \cdot c_i & \text{if } m_i = 1 \\
c_i & \text{if } m_i = 0
\end{cases}
$$

다음으로 attention 단계에서 가중치 $\beta$(예: 3)로 영역 토큰의 어텐션 확률을 키운다. $e_i$는 한 어텐션 헤드의 softmax 이전 query-key 점수, $N$은 입력 토큰 수다. 각 토큰의 $\exp(e_i)$에 $\beta^{m_i}$를 곱하는 것은 영역 토큰의 점수 $e_i$에 $\log \beta$를 더하는 것과 같다. 저자들은 이 단계가 텍스트 정보가 우세해져 시각 단서가 언어 모델 안에서 희미해지는 경향을 상쇄한다고 설명한다.

$$
p_i = \frac{\beta^{m_i} \cdot \exp(e_i)}{\sum_{j=1}^{N} \beta^{m_j} \cdot \exp(e_j)}
$$

마지막으로 logit 단계에서 $\gamma$(예: 1.5)로 두 branch의 다음 토큰 로그확률을 결합한다. 식을 정리하면 guided branch의 로그확률에 두 branch의 차이를 $(\gamma-1)$배 더하는 형태가 된다. $\gamma=1$이면 guided branch만 쓰고, $\gamma>1$이면 영역을 지웠을 때 사라지는 신호를 증폭한다.

$$
\begin{aligned}
\mathbb{P}_{\mathcal{Y}} &= (1-\gamma) \log P_\theta(\mathcal{Y} \mid \bar{\mathbf{c}}) + \gamma \log P_\theta(\mathcal{Y} \mid \mathbf{c}) \\
&= \log P_\theta(\mathcal{Y} \mid \mathbf{c}) + (\gamma - 1)\left[\log P_\theta(\mathcal{Y} \mid \mathbf{c}) - \log P_\theta(\mathcal{Y} \mid \bar{\mathbf{c}})\right]
\end{aligned}
$$

저자들은 $\alpha=1$, $\beta=1$, $\gamma=1$로 두면 각각 token, attention, logit 단계의 가이드가 꺼진다고 설명한다. 또한 마스크 $\mathcal{M}$을 텍스트 토큰에 두면 생성 내용을 특정 주제에 맞추는 데도 같은 틀을 쓸 수 있다고 덧붙인다.

## Experiments

기준 모델은 PubMedVision으로 LoRA fine-tuning한 Phi3.5V-Med(zero-shot)와 이를 각 데이터셋에 추가 fine-tuning한 모델이며, 모두 greedy decoding을 기본으로 VCD, DoLa, OPERA와 비교한다. 데이터셋은 MIMIC-Ext-VQA(흉부 X-ray, bbox가 있는 질문만 사용해 bbox 영역을 채운 마스크), SLAKE(복부 CT·흉부 X-ray·뇌 MRI), 저자들이 구축한 안구 B-scan 초음파 데이터셋 OBScan(안과 전문의가 망막, 수정체, 유리체 혼탁, 유리체 박리 영역을 분할)이고, closed 질문은 정확도, open 질문은 정답 토큰이 응답에 포함된 비율(recall)로 평가한다.

![Table 1 세 데이터셋 결과](/assets/img/posts/2512.17189/table1-main-results.webp)
_Table 1. 세 데이터셋에서의 방법별 성능_

- **세 데이터셋 전반의 정확도 향상**
  - zero-shot과 fine-tuning 두 설정 모두에서 ARCD가 기준 모델의 overall 정확도를 높이고 VCD, DoLa보다 일관되게 앞선다는 주장
  - 원인을 분할 마스크가 주는 해부학적 사전정보가 어텐션을 임상적으로 관련된 구조에 묶기 때문으로 설명

- **진단 지식과 공간 가이드의 상호작용**
  - zero-shot에서 세밀한 MIMIC의 향상 폭이 작은 것은 마스크가 공간 가이드를 주더라도 모델에 전문 진단 지식이 부족하기 때문이라는 해석
  - MIMIC에 fine-tuning한 모델은 이 지식을 갖춰 가이드를 온전히 활용하므로 가장 큰 향상을 보인다는 주장

- **fine-tuning과 ARCD에 따른 응답 유형 변화**
  - 250개 샘플의 응답을 GPT-4o가 다섯 유형으로 분류한 결과, 일반·과제별 의료 데이터 fine-tuning이 환각과 거부 응답을 크게 줄이고, ARCD는 모든 설정에서 완전 정답(Correct) 비율을 높인다는 주장
  - MIMIC은 보고서에 여러 질환이 함께 서술되어 fine-tuning 모델이 그럴듯하지만 검증되지 않은 정보를 더 만들 수 있으므로 전문가 검토가 필요하다는 언급

  - fine-tuning 모델에서도 $\alpha$는 성능에 거의 영향을 주지 않아 0.01로 고정했다는 설명
  - Table 1에는 가장 높은 설정이 아니라 안정적인 설정의 결과를 보고했다는 입장

_Figure 5. 입력 이미지를 바꾸는 시각 프롬프트와의 비교_

- **입력 이미지 조작 방식과의 비교**
  - 중앙 crop, ROI crop, 배경 마스킹, bbox 오버레이 같은 단순한 시각 프롬프트보다 ARCD가 앞선다는 주장
  - MIMIC에서는 중앙 crop이 눈에 띄는 향상을 보이고, OBS에서는 crop이 오히려 해로운데 잘려 나간 텍스트 정보가 유용한 사전정보였기 때문이라는 추정
  - bbox 오버레이만으로도 안정적인 향상이 나오는 점을 어텐션 사전정보가 정확도와 신뢰성에 중요하다는 간접 근거로 제시

- **전문가 주석 없는 자동 마스크의 활용**
  - torchxrayvision의 PSPNet으로 장기를 분할하고 외접 사각형을 bbox로 써서 전문가 주석을 대체해도 zero-shot과 fine-tuning 모두에서 향상이 유지된다는 주장
  - 높은 IoU 기준에서 정밀도가 낮은 것은 예측이 "right lung" 같은 넓은 범주이고 정답은 "right mid lung zone" 같은 세부 영역이라 생기는 입도 차이이며, 전체 성능 향상을 막지 않는다는 설명

## Limitations & Thoughts

- **Prompt Highlighter와 같은 메커니즘**
  - token 단계의 $\alpha$ 임베딩 축소(기본값 0.01까지), attention 단계의 $\beta^{m_i}$ 증폭, logit 단계의 classifier-free guidance 결합은 Prompt Highlighter(CVPR 2024)의 식과 형태가 같고, Prompt Highlighter도 LLaVA의 이미지 patch 토큰 강조를 이미 다룸. 공개 코드도 `highlighter_modules` 같은 같은 계열 모듈 이름을 사용
  - 논문은 방법을 "VCD의 확장"으로 소개하고 Prompt Highlighter는 텍스트 정렬 응용에서만 인용하며 직접 비교도 없음. 새로운 부분은 Phi-3.5V 토큰 배치에 맞춘 마스크 변환과 해부학 분할 마스크를 가이드로 쓰는 의료 적용·검증으로 보는 편이 정확

- **정답 영역 정보를 받는 비교의 공정성**
  - 마스크는 질문과 관련된 영역의 주석(MIMIC은 Chest ImaGenome bbox, OBScan은 전문의 분할)에서 오지만, VCD·DoLa·OPERA는 이 정보 없이 원 논문의 기본 하이퍼파라미터로 비교됨
  - OBScan 주석에는 유리체 혼탁, 유리체 박리 같은 병변 영역이 포함되어, 질문이 그 병변을 묻는 경우 마스크가 공간 가이드를 넘어 답의 단서가 될 여지
  - 같은 영역 정보를 받는 조건끼리의 비교는 Figure 5뿐이고, ARCD와 bbox 오버레이의 차이는 몇 점 수준. 자동 마스크 실험(Table 6)도 MIMIC의 장기 수준 분할에 한정

- **평가 규모와 하이퍼파라미터 선택**
  - Table 1의 백분율을 역산하면 세 데이터셋 모두 254문항(MIMIC open 63·closed 191, SLAKE 127·127, OBScan 90·164) 기준이며, 부록 통계의 SLAKE·MIMIC test 규모보다 작은데 선택 기준은 적혀 있지 않음. overall 1문항이 약 0.39%p라 +0.79 같은 차이는 2문항 수준
  - zero-shot 보고값은 세 데이터셋 모두 Figure 4 격자의 최댓값과 같고(OBScan은 반올림 차이), Table 4의 정확도도 Table 1과 일치해 설정 탐색과 최종 보고가 같은 평가 집합에서 이뤄짐
  - 식대로라면 $\beta=1, \gamma=1$은 기준 모델과 같아야 하는데, Figure 4에서 MIMIC만 기준 값과 같고 SLAKE와 OBScan은 다르며 설명이 없음

- **세 단계 각각의 기여**
  - Table 4에서 $\alpha$를 0, 0.01, 0.1로 바꿔도 정확도가 소수점 넷째 자리까지 같아, token 단계가 정답 여부를 바꾸지 않음
  - Figure 4에서 향상을 이끄는 단계가 데이터셋마다 다름: MIMIC은 $\gamma=1$에서 $\beta$만 올려도 향상 대부분이 나오지만, OBScan은 $\gamma=1$이면 $\beta$를 올려도 기준 값에 머묾
  - "verifiably steers the model's focus"라는 표현과 달리, 어텐션이 지정 영역으로 옮겨졌는지 정량화한 분석은 없음

- **환각 평가의 성격**
  - 주 지표는 closed 정확도와 open recall이고, Figure 3의 GPT-4o 프롬프트에서 Hallucination 범주는 "짧은 정답을 포함하지 않고 정답과 모순"으로 정의되어 오답과 거의 같은 개념
  - 부록 프롬프트의 세 번째 범주 이름(Correct but Incorrectly Specific)이 그림 범례(Correct with Detail Nuances)와 다르고, MIMIC zero-shot과 OBS fine-tuning은 ARCD 전후 환각 비율 차이가 거의 보이지 않음

- **일반화 주장의 범위와 표기 문제**
  - "여러 VLM에 결합 가능"을 기여로 내세우지만 실험 백본은 Phi-3.5V 계열 하나이고, 마스크 변환이 Phi-3.5V의 뷰 분할과 줄바꿈 토큰 배치에 맞춰져 있어 다른 모델로 옮기려면 재설계 필요
  - 짧은 답의 VQA 중심이라 판독문 생성 같은 긴 출력에서의 효과는 미검증
  - Figure 2는 unguided를 $\mathbf{c}$, guided를 $\bar{\mathbf{c}}$로 표시해 본문 식과 반대

- **후속 연구와의 연결**
  - CAST(MICCAI 2026)는 수동 주석 없이 분할 모델로 해부 영역을 찾고, 가렸을 때 가능도가 떨어지는 정도로 인과적으로 중요한 영역만 골라 classifier-free guidance와 시간축 대비를 결합해 ARCD의 주석 의존성을 겨냥
  - "어느 영역을 볼지"를 정답 주석이 정하는 설정에서 모델 스스로 근거 영역을 찾는 설정으로 옮겨 가는 흐름
