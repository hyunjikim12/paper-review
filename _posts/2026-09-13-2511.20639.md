## Summary

LatentMAS는 LLM 에이전트들이 텍스트 대신 잠재 공간(latent space)에서 추론하고 소통하는 training-free 멀티에이전트 시스템(multi-agent system, MAS)이다. 각 에이전트는 마지막 층 hidden state로 잠재 사고(latent thoughts)를 생성해 KV cache에 담아 다음 에이전트에 넘기고, 마지막 에이전트만 답을 텍스트로 디코딩한다.

- **기여 1. 순수 잠재 협업 프레임워크**
  - 에이전트 내부 추론과 에이전트 간 전달을 모두 잠재 공간에서 수행하는 학습 없는 구조

- **기여 2. 입력-출력 정렬 행렬**
  - hidden state를 입력 임베딩 분포로 되돌리는 선형 사상의 닫힌 형태 계산

- **기여 3. 표현력·전달 충실도·복잡도의 이론 분석**
  - 잠재 사고의 표현력 하한, KV cache 전달의 정보 보존, 텍스트 기반 MAS 대비 낮은 복잡도 증명

- **기여 4. 정확도와 효율의 동시 개선**
  - 9개 벤치마크에서 최대 14.6% 정확도 향상, 출력 토큰 70.8~83.7% 감소, 4~4.3배 빠른 추론

## Background

LLM 기반 MAS는 여러 에이전트가 역할을 나눠 협업하며, 각 에이전트의 생각과 에이전트 간 소통을 텍스트가 매개한다. 뒤 에이전트는 앞 에이전트가 생성한 텍스트를 입력으로 다시 읽고 이어서 추론한다.

| 계열 | 대표 연구 | 방식 | 한계 |
|---|---|---|---|
| 텍스트 기반 MAS | Chain of Agents, AutoGen, CAMEL | 명시적 대화와 역할 분담으로 협업 | 모든 생각과 소통을 텍스트로 디코딩하고 다시 입력 |
| 단일 모델 잠재 추론 | Coconut, Soft Thinking | hidden state로 연쇄 추론(chain-of-thought)을 대체 | 한 모델 내부에 한정, 에이전트 간 협업 미고려 |
| 모델 간 잠재 통신 | Cache-to-Cache, KVComm, Thought Communication | hidden state나 KV cache로 모델 간 정보 교환 | 대부분 정렬 모듈 학습 필요, 주로 입력 문맥만 공유 |

세 계열은 텍스트를 매개로 협업하거나, 잠재 추론과 잠재 통신 중 한쪽만 다룬다. 저자들은 둘을 하나로 묶은 협업 프레임워크가 없다고 보고, MAS가 잠재 공간만으로 협업할 수 있는지를 문제로 제기한다.

## Method

텍스트 기반 MAS에서는 에이전트 $A_1$이 생각을 토큰으로 디코딩하고 $A_2$가 그 텍스트를 다시 인코딩한다. LatentMAS는 두 단계를 모두 생략한다. $A_1$은 마지막 층 hidden state로 토큰을 고르는 대신 그 벡터를 다음 스텝의 입력 임베딩으로 넣고, 이를 $m$번 반복해 잠재 사고를 만든다. 이때 $A_1$의 모든 층 KV cache에는 입력과 잠재 사고가 함께 쌓이며, $A_2$는 이 KV cache를 자신의 KV cache 앞에 층별로 이어 붙여 $A_1$의 문맥과 사고를 직접 읽은 것과 같은 조건에서 계산한다. KV cache를 그대로 이어 붙이므로 모든 에이전트는 같은 층 구조를 가져야 하며, 실험도 설정마다 하나의 백본에 역할별 프롬프트를 달리해 에이전트를 구성한다.

이 구성은 Background의 한계에 각각 대응한다. 중간 에이전트는 텍스트를 디코딩하거나 다시 인코딩하지 않고, 단일 모델의 잠재 추론은 KV cache 전달과 결합해 협업으로 확장되며, 정렬 행렬은 학습 없이 계산되고 입력 문맥뿐 아니라 새로 생성한 잠재 사고까지 전달된다.

### Preliminary and Notations

Transformer $f_\theta$는 입력 토큰을 임베딩 $$E=[e_1,\dots,e_t]$$로 바꾸고 $L$개 층을 통과시켜 마지막 층 hidden state $$H=[h_1,\dots,h_t] \in \mathbb{R}^{t \times d_h}$$를 얻는다. 일반적인 생성은 언어 모델 헤드 $$W_{out}$$으로 다음 토큰을 고르고, 잠재 생성은 이 디코딩을 거치지 않고 hidden state를 이어서 생성한다.

$$
f_\theta(x_{t+1} \mid x_{\le t}) = \mathrm{softmax}(h_t W_{out})
$$

KV cache는 매 스텝 새 key와 value를 층마다 누적해 재계산을 피하는 작업 메모리(working memory)다.

$$
K_{cache} \leftarrow [K_{\le t}; K_{t+1}], \qquad V_{cache} \leftarrow [V_{\le t}; V_{t+1}]
$$

MAS는 LLM 에이전트 $$\mathcal{A}=\{A_1,\dots,A_N\}$$로 구성된다. 순차형(sequential) MAS에서는 planner, critic, refiner, solver가 차례로 앞 에이전트의 출력을 이어받고, 계층형(hierarchical) MAS에서는 code, math, science 에이전트가 각자 추론한 결과를 summarizer가 종합한다.

![순차형·계층형 MAS 구조](/assets/img/posts/2511.20639/fig2-mas-settings.webp){: w="320" }
_Figure 2. 순차형·계층형 MAS 설정_

이론 분석은 선형 표현 가설(linear representation hypothesis)을 전제로 한다. hidden state $h$는 선형 독립인 의미 기저 $$\{s_1,\dots,s_{d_h}\}$$의 결합 $$h=\sum_i c_i s_i$$이고, 각 계수 $$c_i \in \{0, \pm 1\}$$는 해당 의미의 부재 또는 양·음의 존재를 나타낸다. 이 가정 아래 저자들은 잠재 사고 $m$스텝을 텍스트로 손실 없이 옮기는 데 필요한 토큰 수가 다음과 같음을 보인다(Theorem 3.1).

$$
m' \geq \frac{d_h m \log 3}{\log \lvert V \rvert} = \Omega\left(\frac{d_h m}{\log \lvert V \rvert}\right)
$$

즉 잠재 사고 한 스텝은 토큰 $d_h / \log \lvert V \rvert$개 분량의 정보를 담을 수 있으며, 저자들은 이 비율을 Qwen3-4B, 8B, 14B에서 각각 235.7, 377.1, 471.4배로 계산한다.

### Auto-regressive Latent Thoughts Generation

마지막 층 hidden state는 입력 토큰 임베딩과 분포가 달라, 그대로 입력하면 분포 밖(out-of-distribution) 활성값이 생길 수 있다. 저자들은 입력 임베딩 행렬 $$W_{in}$$과 출력 임베딩 행렬 $$W_{out}$$만으로 정렬 행렬 $W_a$를 구한다.

$$
e = h W_a, \qquad W_a = \frac{1}{\beta}\left(W_{out}^{\top} W_{out} + \lambda I\right)^{-1} W_{out}^{\top} W_{in}
$$

$\beta$는 출력 임베딩의 크기 보정 계수, $\lambda$는 작은 ridge 항이다. 이 해는 정렬된 임베딩 분포와 토큰 임베딩 분포 사이 Wasserstein 거리의 상한 $$\lVert \beta W_{out} W_a - W_{in} \rVert_F$$를 최소화하며, $d_h \times d_h$ 크기로 한 번만 계산해 모든 잠재 스텝에 재사용한다. Figure 6에서 정렬 전 hidden state $h_t$는 입력 임베딩 $e_t$의 분포에서 멀리 떨어져 있지만, $W_a$를 적용한 벡터는 입력 임베딩 분포와 다시 겹친다.

### Thoughts Transfer via Latent Working Memory

$A_1$은 잠재 사고 생성을 마친 뒤 모든 층의 KV cache를 모아 잠재 작업 메모리로 넘긴다.

$$
\mathcal{M}_{A_1} = \left\{ \left(K^{(l)}_{A_1,\mathrm{cache}},\, V^{(l)}_{A_1,\mathrm{cache}}\right) \;\middle|\; l = 1, \dots, L \right\}
$$

각 층은 입력 $t$개와 잠재 사고 $m$개의 위치를 담는다. 저자들은 이를 받은 $A_2$의 출력이 앞 에이전트의 출력을 직접 입력한 경우와 같음을 증명하고(Theorem 3.3), hidden state 대신 KV cache를 넘겨 재계산을 없앤다. 에이전트당 시간 복잡도는 $$O\left((d_h^2 m + d_h m^2 + d_h t m) L\right)$$로, 같은 표현력에 더 많은 스텝과 어휘 디코딩 비용이 드는 텍스트 기반 MAS보다 낮다(Theorem 3.4).

## Limitations & Thoughts

- **같은 구조의 모델끼리만 가능한 협업**
  - 실험은 한 백본이 역할 프롬프트만 바꿔 앞선 계산 위에 이어서 추론하는 구조라, 여러 에이전트의 협업과 긴 단일 추론의 분할 사이 경계가 불분명
  - 저자도 이종 모델에는 학습 가능한 어댑터가 필요하다고 부록에서 인정. Vision Wormhole은 VLM 시각 입력 경로를 공용 채널로 삼아 이 제약을 다룸

- **이론 주장의 범위**
  - Theorem 3.3의 무손실 전달은 KV cache 재사용이 재계산과 같다는 성질이며, 다음 에이전트가 앞선 사고를 유용하게 쓴다는 보장은 아님
  - Theorem 3.1은 계수를 세 값으로 가정해 상태 수를 센 결과라, 471.4배는 정보 용량의 상한이지 실제 추론 효율이 아님

- **작은 정확도 차이와 평가 규모**
  - TextMAS 대비 평균 향상은 순차형 2.8%, 계층형 4.6%이고, Table 1에도 Qwen3-4B GSM8K, Qwen3-8B·14B ARC-C처럼 더 낮은 결과 존재
  - AIME24·25는 각 30문항이라 3.3%p가 한 문제. 세 번 실행 평균이지만 분산은 보고되지 않았고, 과제별로 선택한 잠재 스텝 수도 본문에 없음
  - 속도 이득의 상당 부분은 긴 텍스트 디코딩 생략에서 오며, AIME에서 TextMAS 최대 출력 길이를 20,000 토큰으로 둔 설정과 함께 해석해야 함

- **해석 가능성과 안전성**
  - 중간 사고가 텍스트로 남지 않고, 저자의 debug mode는 텍스트 응답을 병렬로 추가 생성하는 방식이라 효율 이점과 충돌
  - LCGuard는 LatentMAS 방식의 KV 공유에서 재구성 공격으로 민감 정보가 드러남을 보였고, When Latent Agents Lie는 악의적 에이전트의 KV cache 조작을 다룸

- **지금 시점의 의의**
  - 잠재 추론과 잠재 통신을 학습 없이 하나의 MAS로 묶은 기준점
  - 같은 1저자의 Recursive MAS가 재귀 구조로 확장했고, Vision Wormhole은 같은 평가 구성으로 이종 모델에 적용했으며, Cache Merging은 KV cache를 순서와 무관하게 병합하는 방식을 제안
