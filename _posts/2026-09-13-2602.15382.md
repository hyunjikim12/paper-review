## Summary

Vision Wormhole은 서로 다른 계열의 시각-언어 모델(vision-language model, VLM) 에이전트가 텍스트 대신 VLM의 이미지 토큰 입력 자리(vision-token span)로 잠재 메시지를 주고받게 하는 통신 방식이다. 모델마다 학습한 codec이 보내는 쪽의 추론 상태를 공용 참조 공간의 토큰으로 압축하고, 받는 쪽 codec이 이를 이미지 임베딩 자리에 주입하며, VLM 백본은 모두 고정된다.

- **기여 1. Vision Wormhole 메커니즘**
  - VLM의 비전 입력 경로를 이종 에이전트 간 연속 통신 인터페이스로 재해석

- **기여 2. 범용 codec과 O(N) 확장성**
  - 공용 참조 공간을 둔 hub-and-spoke 구조로, 새 모델 계열은 codec 하나만 학습

- **기여 3. 레이블 없는 증류 기반 정렬**
  - 텍스트 채널을 teacher, 비전 채널을 student로 두어 모델 간 hidden state 쌍 없이 codec 학습

- **기여 4. 이종 VLM 구성에서의 실험 검증**
  - 4개 VLM 계열, 9개 벤치마크에서 대부분 설정의 추론 시간 감소와 macro 평균 정확도 향상

## Background

서로 다른 계열의 모델은 토크나이저, hidden 차원, 표현 공간이 달라 내부 상태를 그대로 주고받을 수 없다. 저자들은 이종 모델 간 잠재 통신의 난관으로 세 가지를 든다. 텍스트 전용 LLM에 임의의 연속 벡터를 넣으면 학습 분포를 벗어나 생성이 무너지는 분포 이탈(off-manifold) 문제, 모델 쌍마다 변환기를 두면 $N$개 모델에 $N(N-1)$개가 필요한 확장성 문제, 두 모델의 hidden state를 짝지은 정렬 데이터가 없는 감독 신호 부재 문제다.

- **① 텍스트 기반 MAS (AutoGen, MetaGPT, CAMEL, Chain of Agents)**
  - **방식**: 역할을 나눈 에이전트들이 자연어 메시지로 협업
  - **한계**: 중간 메시지 디코딩에 따른 실행 시간·대역폭 병목, 내부 추론을 이산 텍스트로 압축할 때의 정보 손실

- **② 같은 백본 간 학습 없는 잠재 통신 ([LatentMAS](/paper-review/posts/2511.20639/), KVComm)**
  - **방식**: hidden state나 KV cache를 추가 학습 없이 직접 교환
  - **한계**: 층 구조와 hidden 차원이 호환되는 같은 계열 모델 전제, 독립적으로 학습된 다른 계열에는 적용 불가

- **③ 학습된 모델 간 변환기 (Cache-to-Cache, Thought Communication)**
  - **방식**: 한 모델의 내부 상태를 다른 모델 공간으로 옮기는 변환 모듈 학습
  - **한계**: 모델 쌍마다 학습해야 하는 제곱 비용, 백본에 버금가는 어댑터 크기와 대량의 학습 데이터

- **④ 단일 모델 잠재 추론 (Coconut, Soft Thinking)**
  - **방식**: 한 모델이 연속 공간에서 사고해 추론 토큰을 줄임
  - **한계**: 한 모델 내부 효율에 한정, 다른 모델이 그 신호를 읽게 하는 상호운용성은 미고려

![네 가지 통신 방식 비교](/assets/img/posts/2602.15382/fig1-paradigms.webp)
_Figure 1. 텍스트, 모델 쌍 변환기, LatentMAS, Vision Wormhole의 통신 방식 비교_

네 계열은 범용이면 대역폭이 낮고, 빠르면 같은 계열에 묶이며, 계열을 넘으면 모델 쌍마다 학습 비용이 들고, 연속 공간을 쓰더라도 한 모델 안에 머문다. 저자들은 모델 쌍마다 변환기를 학습하지 않고도 서로 다른 계열의 에이전트가 텍스트를 거치지 않고 잠재 상태를 주고받는 경로가 필요하다고 본다.

## Method

Vision Wormhole은 VLM이 이미지 임베딩이라는 연속 벡터열을 입력으로 받도록 이미 학습되어 있다는 점을 이용한다. 보내는 에이전트는 텍스트를 생성하는 대신 hidden state를 크기만 맞춰 다시 입력으로 넣는 latent rollout으로 추론 상태를 요약하고, codec의 encoder가 이를 고정 개수의 universal token으로 압축한다. 이 토큰은 모델별 affine map을 거쳐 모든 에이전트가 공유하는 참조 공간(reference space)으로 옮겨진다. 받는 에이전트는 자기 affine map으로 메시지를 가져오고, codec의 decoder가 이를 고정 더미 이미지의 임베딩에 더할 벡터로 바꾼다. 결과적으로 받는 VLM은 텍스트가 아니라 이미지 자리를 통해 앞 에이전트의 추론 상태를 읽으며, 학습되는 것은 모델별 codec과 affine map뿐이다.

이 구성은 Background의 한계에 각각 대응한다. 중간 에이전트는 텍스트를 생성하지 않고 크기가 고정된 연속 메시지를 넘긴다. 같은 백본 대신 모델별 codec과 공용 참조 공간으로 다른 계열을 연결하며, 모델 쌍 변환기 대신 모델당 codec 하나와 affine map 두 개만 두어 모듈 수가 모델 수에 선형으로 늘어난다. 정렬 데이터 부재는 텍스트로 받은 경우를 teacher로 삼는 증류로, 분포 이탈은 연속 입력용으로 학습된 이미지 토큰 자리에 잔차로 주입하는 방식으로 다룬다.

### Preliminaries

MAS는 에이전트 집합 $$\mathcal{A}=\{a_1,\dots,a_N\}$$와 역할 순서와 메시지 경로를 정하는 조율 정책 $\pi$로 정의된다. 각 에이전트는 고정된 VLM 백본 $F_i$와 임베딩 차원 $d_i$를 가진다. VLM은 텍스트 토큰 임베딩과 이미지 토큰 구간을 이어 입력을 만들며, 이미지 $I$는 비전 인코더와 projector를 거쳐 연속 벡터열이 된다.

$$
X^{(i)}_{img} = \phi_i\left(E^{(i)}_{vis}(I)\right) \in \mathbb{R}^{L^{(i)}_{img} \times d_i}
$$

메시지 재료인 latent rollout은 프롬프트 끝 hidden state에서 시작해, 이전 hidden state의 크기를 토큰 임베딩의 평균 크기 $\alpha_i$에 맞춘 벡터를 다음 입력으로 넣기를 $T$번 반복해 얻는다.

$$
x^{(i)}_t = \alpha_i \frac{h^{(i)}_t}{\lVert h^{(i)}_t \rVert_2 + \epsilon}, \qquad H_i = \left[x^{(i)}_0, \dots, x^{(i)}_{T-1}\right] \in \mathbb{R}^{T \times d_i}
$$

메시지 하나는 공통 차원 $D$의 universal token $K_u = K+2$개(의미 토큰 $K$개와 전역·스타일 토큰)로 표현된다.

### Training a Vision Codec for a Specific VLM

encoder $E_i$는 Perceiver 방식의 resampler로 $$U_i = E_i(H_i) \in \mathbb{R}^{K_u \times D}$$를 만들고, decoder $D_i$는 universal token을 이미지 구간 섭동 $\Delta_i$와 게이트 $$g_i \in (0,1)$$로 바꿔 더미 이미지 임베딩 $$\bar{X}^{(i)}_{img}$$에 잔차로 더한다.

$$
X^{(i)}_{img} = \bar{X}^{(i)}_{img} + g_i \cdot \mathrm{Resample}\left(\Delta_i;\, L^{(i)}_{img}\right)
$$

학습은 짧은 텍스트 앵커 $m$으로 한다. teacher 프롬프트는 $m$을 텍스트로 포함하고 student 프롬프트는 위 식으로 덮어쓴 더미 이미지를 포함하며, 백본을 고정한 채 프롬프트 경계의 hidden state, 다음 토큰 분포, 주입 크기를 맞추도록 codec만 학습한다.

$$
\mathcal{L}_{codec} = \lambda_h \left\lVert h_{vis} - \mathrm{sg}(h_{text}) \right\rVert_2^2 + \lambda_{kl} \tau^2\, \mathrm{KL}\left(\mathrm{softmax}(\ell_{text}/\tau) \,\Vert\, \mathrm{softmax}(\ell_{vis}/\tau)\right) + \lambda_{rms} \left(\mathrm{RMS}(\Delta_{inj}) - \mathrm{RMS}(\bar{X}^{(i)}_{img})\right)^2
$$

기본 설정은 $D=512$, $K_u=1024$, $T=1024$이고, 앵커 3,000개(약한 감독 설정은 90개)로 400 스텝 학습한다.

### Aligning Codecs Across Agents via an Affine Map in Universal Space

따로 학습한 codec의 universal token은 차원은 같아도 좌표계가 다르다. 저자들은 기준 에이전트 $r$을 정하고, 각 에이전트에 참조 공간으로 보내는 map $$A^{out}_i(U) = U W^{out}_i + \mathbf{1}(b^{out}_i)^{\top}$$와 받는 map $$A^{in}_i$$를 두어, 공통 앵커에 대한 universal token을 기준 모델에 맞추는 ridge 회귀로 닫힌 형태로 구한다.

$$
\min_{W^{out}_i,\, b^{out}_i} \sum_{j=1}^{M} \left\lVert U_i(m_j) W^{out}_i + \mathbf{1}\left(b^{out}_i\right)^{\top} - U_r(m_j) \right\rVert_F^2 + \lambda \left\lVert W^{out}_i \right\rVert_F^2
$$

### Inference: Multi-Agent Collaboration through the Vision Wormhole

에이전트 $s$에서 $i$로 가는 메시지는 다음과 같이 계산되어 수신자의 이미지 토큰 구간에 쓰인다.

$$
U^{ref}_{s \to i} = A^{out}_s\left(E_s(H_s)\right), \qquad (\Delta_i, g_i) = D_i\left(A^{in}_i\left(U^{ref}_{s \to i}\right)\right)
$$

메시지는 참조 공간의 공유 메모리에 이어 붙여 쌓인다. 각 역할 에이전트는 메모리를 이미지 구간으로 읽고, latent rollout으로 생각한 뒤, 새 메시지를 메모리에 쓴다. 마지막 에이전트만 텍스트로 답하며, 메시지 추출과 수신 비용은 각각 $T$ 스텝과 이미지 토큰 길이로 고정된다.

## Experiments

LatentMAS의 평가 구성인 9개 벤치마크에서 Qwen3-VL-2B, Gemma-3-4B, SmolVLM2-2.2B, LFM2.5-VL-1.6B로 만든 이종 구성(두 백본 다섯 가지, 네 백본 한 가지)을 Planner, Critic, Refiner, Judger 순차 워크플로로 실행하고, 같은 프롬프트의 TextMAS와 비교한다.

## Limitations & Thoughts

- **학습이 필요한 통신과 보고되지 않은 비용**
  - [LatentMAS](/paper-review/posts/2511.20639/)와 달리 모델마다 codec을 앵커 3,000개로 학습해야 하고, 메시지마다 latent rollout을 1,024 스텝 실행
  - "모델 쌍 변환기보다 가볍다"는 주장의 정량 근거는 Cache-to-Cache 어댑터 818.4MB라는 각주뿐이며, codec의 파라미터 수와 학습 시간은 보고되지 않음
  - Table 1에서 오히려 느려진 칸이 7개이고, 가장 느린 경우 0.57배

- **정확도 이득의 해석**
  - Table 1의 Gemma-3-4B(P/R)·Qwen3-VL-2B(C/J) 구성은 9개 과제 중 5개에서 TextMAS보다 낮음
  - Table 6의 Gemma-3-4B 단일 성능(MBPP-Plus 71.2%, HumanEval-Plus 65.8%)은 Table 1의 모든 Vision Wormhole 결과(최고 67.7%, 60.4%)보다 높아, 코드 생성 이득은 가장 강한 단일 모델에 못 미치는 MAS 안에서 약한 TextMAS 대비로 측정된 것
  - greedy decoding 한 번의 결과로 분산이 없고, AIME는 30문항이라 3.3%p가 한 문제

- **비교 대상의 공백**
  - 동기로 든 Cache-to-Cache 등 학습된 변환기와의 직접 비교 부재
  - 같은 백본 설정에서 LatentMAS와 비교해 codec 학습의 비용과 이득을 따진 실험 부재

- **적용 범위와 해석 가능성**
  - VLM의 이미지 입력 경로에 의존해 텍스트 전용 LLM 에이전트에는 적용 불가 (저자도 명시)
  - 메시지가 사람이 읽을 수 없는 임베딩이라 중간 추론 검증이 어렵고, affine 정렬이 통하는 이유는 가설 수준

- **계보 속 의의**
  - LatentMAS가 남긴 이종 모델 확장 과제를 백본 수정 없이 VLM 비전 입력 경로로 푼 시도
  - 후속 연구인 Post-Hoc Sparse Coding은 이 채널의 잠재 메시지를 sparse autoencoder로 압축해 전송 크기를 크게 줄임
