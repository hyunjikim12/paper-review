## Summary

ProM3E는 생태학 데이터의 여섯 모달리티(지상 종 이미지, 위성 이미지, 지리 위치, 종 소리, 분류학 텍스트, 환경 변수) 가운데 일부만 주어졌을 때 나머지 모달리티의 임베딩을 임베딩 공간에서 확률적으로 예측하는 다중 모달 임베딩 모델이다. 먼저 모든 모달리티를 하나의 공간으로 정렬한 뒤, 가려진 모달리티의 전역 임베딩을 복원하는 masked variational autoencoder(MVAE)를 학습해 입력 모달리티 조합에 대한 가우시안 분포와 그 불확실성을 얻는다.

- **기여 1. 임베딩 공간의 any-to-any 생성**
  - 입력 모달리티들의 결합 분포를 학습해 없는 모달리티의 임베딩을 복원하는 프레임워크

- **기여 2. 모달리티 역변환 기반 교차 모달 검색**
  - 질의 임베딩과 복원한 타깃 모달리티 임베딩을 섞어 모달리티 간 유사도와 모달리티 내 유사도를 함께 쓰는 검색

- **기여 3. 불확실성 분석**
  - 예측 분포의 폭으로 가장 정보가 많은 모달리티를 찾고, 모달리티를 합칠 때 불확실성이 줄어드는지에 대한 분석

- **기여 4. Modality gap 분석**
  - 학습 전후와 모달리티 추가에 따른 modality gap의 변화, 그리고 불확실성과의 관계 분석

## Background

다중 모달 모델은 원격 탐사, 생태학, 의료 같은 분야별로 발전했지만, 추론 때 일부 또는 모든 모달리티가 있다고 가정하거나 빠진 모달리티를 추론하지 못한다. 생태 관측에서는 한 위치의 위성 이미지가 여러 지상 이미지와 대응하듯 모달리티 사이가 일대일로 짝지어지지 않고, 초분광 영상처럼 얻기도 합성하기도 어려운 모달리티가 있다.

- **① Any-to-any 다중 모달 모델 (4M, MultiMAE, AnySat, Galileo)**
  - **방식**: 일부 모달리티를 가리고 나머지로 복원하는 masked modeling이나 JEPA와 비슷한 student-teacher 구조로 임의의 모달리티를 생성
  - **한계**: 모든 모달리티가 짝지어진 대규모 데이터가 필요하고, 짝 데이터를 기성 모델로 합성하는 방식은 초분광이나 MRI처럼 합성이 어려운 모달리티에 쓸 수 없음

- **② 대조 학습 기반 공통 임베딩 (ImageBind, TaxaBind, BioCLIP)**
  - **방식**: 이미지와 짝지어진 데이터로 각 모달리티 인코더를 이미지 공간에 대조 정렬
  - **한계**: 추론 때 모달리티가 주어진다고 가정해 빠진 모달리티를 추론하지 못함

- **③ 확률적 표현 학습 (PCME, PCME++, ProLIP)**
  - **방식**: 입력을 점이 아닌 가우시안 분포로 표현하고 Monte Carlo 샘플링이나 닫힌 형태 근사로 교차 모달 유사도를 학습
  - **한계**: 이미지와 텍스트 두 모달리티 사이의 표현에 머묾

- **④ Modality gap 연구 (Mind the Gap 등)**
  - **방식**: 다중 모달 임베딩 공간에서 모달리티끼리 떨어져 있는 현상을 초기화, 대조 손실의 동역학, 모달리티 불균형으로 설명
  - **한계**: 두 모달리티 모델을 대상으로 한 분석

네 계열을 합쳐 보면, 대조 정렬 모델은 빠진 모달리티를 채우지 못하고, any-to-any 모델은 모든 모달리티가 짝지어진 대규모 데이터에 기대며, 확률적 표현과 modality gap 연구는 두 모달리티에 머문다. 저자들은 적은 양의 완전 짝 데이터만으로 임의의 입력 조합에서 빠진 모달리티를 임베딩 수준에서 추론하고, 일대다 대응에서 오는 불확실성까지 표현하는 모델이 필요하다고 제기한다.

## Method

ProM3E의 설계는 정렬을 먼저 하고 융합은 나중에 하는 것이다. 이미지와 짝지어진 데이터는 모달리티마다 따로 대규모로 모을 수 있으므로 첫 단계에서 각 모달리티 인코더를 공통 공간에 정렬하고, 둘째 단계는 원본 신호가 아니라 정렬된 전역 임베딩만 받아 적은 완전 짝 데이터로 학습한다. 둘째 단계의 과제는 한두 개 모달리티의 임베딩만 보고 나머지 모달리티의 임베딩을 맞히는 것인데, 같은 위성 이미지에 여러 종이 대응하듯 정답이 하나로 정해지지 않는다. 그래서 인코더는 점 하나 대신 입력 조합에 대한 가우시안 분포 하나를 내고, 모달리티마다 이 분포에서 따로 샘플을 뽑아 모달리티별 디코더로 그 모달리티의 임베딩을 만든다. 논문이 말하는 결합 분포는 모든 모달리티가 공유하는 하나의 잠재 분포이고, 각 모달리티의 값은 디코더가 그 분포에서 읽어 낸다. 복원 오차를 평균제곱오차로 줄이면 가능한 정답들의 중심으로 수렴하므로, 예측이 배치 안 다른 샘플보다 자기 정답에 가깝도록 만드는 대조 손실을 쓴다. 분포의 폭은 입력 모달리티가 가려진 모달리티를 얼마나 잘 설명하는지를 나타내는 신호로 해석된다.

이 구성은 Background의 한계에 각각 대응한다. Any-to-any 모델(①)이 모든 모달리티의 짝 데이터를 대규모로 요구하던 것과 달리 정렬을 이미지 짝 데이터로 분리해 둘째 단계의 짝 데이터 요구를 줄이고, 대조 정렬 모델(②) 위에 가려진 모달리티를 예측하는 단계를 더한다. 확률적 표현(③)을 두 모달리티에서 여섯 모달리티의 결합 분포로 넓히고, modality gap 분석(④)도 셋 이상의 모달리티로 확장한다.

### Multimodal Alignment

모달리티 집합 $$M = \{m_1, \dots, m_6\}$$에 대해 모달리티별 인코더 $$h_i$$가 $j$번째 관측을 정규화된 전역 임베딩 $$f_i^j = h_i(m_i^j)$$로 바꾼다. 지상 이미지와 텍스트는 고정된 BioCLIP 이미지-텍스트 공간을 쓰고, 위성 이미지, 위치(Random Fourier Feature 기반 네트워크), 환경 변수(feedforward 네트워크), 소리는 이미지 짝 데이터와 대칭 SupCon 손실로 지상 이미지에 각각 정렬한다. 정렬은 모달리티마다 독립적으로 하고 TaxaBind의 multimodal patching으로 인코더들을 하나의 공간에 묶는다. 관측 하나를 전역 임베딩 하나로 표현하므로 픽셀 단위 대응이 없는 모달리티끼리도 함께 다룰 수 있다.

### Masked Modality Training

인코더 입력은 모달리티별 2층 projector로 투영한 임베딩 토큰, 위치 인코딩 역할의 모달리티 식별 토큰, 분포의 평균과 로그 분산을 담을 [µ], [σ] 토큰, register 토큰 4개다. 한 층짜리 트랜스포머 인코더를 거친 [µ], [σ] 출력이 입력 모달리티 집합 $G$에 대한 가우시안 분포를 정한다.

$$
\mu_G, \log \sigma_G^2 = E(G), \qquad G \subseteq F
$$

학습 때는 MultiMAE처럼 모달리티를 한두 개만 무작위로 남기고 나머지는 입력에서 버린다. 저자들은 대부분의 모달리티가 없는 실제 상황과 맞는 설정이고, 추론 때는 더 많은 모달리티를 넣어도 활용한다고 설명한다. 디코딩은 재매개변수화로 모달리티마다 샘플을 뽑고, 모달리티별 2층 디코더로 임베딩을 복원한다.

$$
Z_i(G) = \mu_G + \sigma_G \cdot \epsilon_i, \quad \epsilon_i \sim \mathcal{N}(0, 1), \qquad \hat{f}_i(G) = D_i(Z_i(G))
$$

복원 손실은 예측 임베딩과 배치 안 각 정답 임베딩 사이의 유클리드 거리 $$d_i^G(j, p) = \lVert \hat{f}_i^j(G) - f_i^p \rVert_2$$를 scale α와 shift β로 변환해 InfoNCE 형태로 계산한다. 저자들은 대조 형태가 모달리티 내부의 분포를 학습하게 해 중심만 예측하는 것을 막는다고 설명한다. 여기에 예측 분포와 표준 정규분포 사이의 KL 발산인 variational information bottleneck(VIB) 손실을 더해 σ가 0으로 붕괴하지 않게 한다.

$$
\mathcal{L}_{recon}(m_i) = \frac{1}{N} \sum_{j=1}^{N} \frac{e^{\alpha d_i^G(j,j) + \beta}}{\sum_{p=1}^{N} e^{\alpha d_i^G(j,p) + \beta}}
$$

$$
\mathcal{L}_{VIB} = -\frac{1}{2}\left(1 + \log \sigma_G^2 - \mu_G^2 - \sigma_G^2\right)
$$

$$
\mathcal{L} = \frac{1}{\lvert M \rvert} \sum_{i=1}^{\lvert M \rvert} \left( \mathcal{L}_{recon}(m_i) + \lambda \mathcal{L}_{VIB} \right) + \lambda \mathcal{L}_{VIB}
$$

기본 설정은 $\lambda=0.001$, $\alpha=-5$, $\beta=5$, 인코더 차원 1024이고 MVAE 전체는 27M 파라미터다.

### Multimodal Embeddings for Downstream Transfer

학습된 모델에서 하류 과제용 임베딩을 뽑는 방법은 과제마다 다르다. 선형 탐사(linear probing)에는 복원 임베딩보다 인코더의 hidden 표현이 낫고, 그중 register 토큰까지 포함한 모든 토큰을 쓰는 것이 가장 좋다고 보고한다. 교차 모달 검색에서는 모델이 질의 임베딩으로부터 타깃 모달리티의 임베딩을 복원할 수 있다는 점(modality inversion)을 이용해, 질의 임베딩과 복원한 타깃 임베딩을 섞어 최종 질의로 쓴다.

$$
f_q \leftarrow (1 - \delta)\, f_q + \delta\, \hat{f}_t(\{f_q\})
$$

혼합 계수 δ는 MultiNat 검증 분할에서 가장 좋은 값으로 정하고, 섞은 질의와 타깃 임베딩의 코사인 유사도로 검색한다. 저자들은 이 방식이 모달리티 간 유사도와 복원된 타깃 모달리티 안에서의 유사도를 함께 반영한다고 설명한다.

## Experiments

둘째 단계 학습에는 iNaturalist에서 지상 이미지와 소리가 있는 관측을 모아 Sentinel-2 위성 이미지와 WorldClim-2 기후 변수를 붙인 완전 짝 데이터셋 MultiNat을 쓴다. 모달리티 인코더는 사전학습된 TaxaBind로 초기화해 고정하고, MVAE는 H100 한 장에서 학습한다. 평가는 분류학 텍스트 기반 제로샷 종 분류, TaxaBench-8k 교차 모달 검색, BirdCLEF 소리 분류 선형 탐사와 불확실성, modality gap 분석으로 구성된다.

- **셋 이상 모달리티에서의 modality gap**
  - **목적**: 모달리티를 더하거나 인코더를 거칠 때 모달리티 사이의 분리가 줄어드는지 확인
  - 지상 이미지와 위성 이미지의 gap이 다른 모달리티를 더할수록 줄고, 이 경향이 모든 모달리티에서 같다는 주장
  - 입력 표현에서는 모달리티별로 떨어져 있던 임베딩이 hidden 표현에서는 섞여, 학습 방식이 gap을 줄이고 가려진 모달리티 예측을 가능하게 한다는 해석

  - 데이터의 일부만 써도 평균 성능 하락이 작고, 모든 설정에서 TaxaBind를 앞선다는 주장

## Limitations & Thoughts

- **"무엇을 합칠지 학습한다"는 주장의 근거 범위**
  - σ는 입력 조합마다 [σ] 토큰 하나에서 나오고 모든 가려진 모달리티가 같은 분포에서 샘플링되므로, 빠진 모달리티 가운데 어느 것이 불확실한지는 구분하지 못함
  - σ와 복원 오차의 관계는 입력 조합 여섯 개의 평균값 막대에 대한 R²(Figure 4)와 위치 σ와 종 다양성의 Spearman 상관 0.401로만 제시되고, 표본 단위의 보정(calibration) 평가는 없음
  - σ로 입력 모달리티를 고르거나 가중하는 실험이 없고, 검색은 고정된 δ로 섞고 선형 탐사는 hidden 토큰을 써서 불확실성이 하류 결정에 쓰이지 않음
  - Figure 4의 σ 축이 1200에서 시작해, 모달리티별 평균 σ의 차이(약 1325에서 1385)가 실제보다 크게 보임

- **빠진 임베딩 예측 품질의 간접 평가**
  - 복원 임베딩의 정확도는 평균 오차 막대 외에 직접 보고되지 않고 검색과 분류 성능으로만 간접 평가
  - 선형 탐사에서 복원 임베딩은 hidden 토큰 전체보다 평균 약 8점 낮고(Table 10), 이미지 하나로 하는 제로샷 분류에서는 복원 임베딩만 쓰면 TaxaBind보다 낮음(Table 14, 33.23 대 34.45)
  - any-to-any 생성을 내세우지만 성능 향상은 복원 임베딩 자체보다 hidden 표현과 질의 혼합에서 주로 나옴

- **비교 대상과 설정**
  - 주 비교 대상 TaxaBind는 같은 저자들의 이전 모델이자 ProM3E 인코더의 초기값이라, 결과는 사실상 TaxaBind 인코더 위에 MVAE를 더한 효과
  - ImageBind와 TaxaBind에 여러 모달리티를 함께 넣을 때 임베딩을 어떻게 결합했는지 본문에 설명이 없음
  - 4M, MultiMAE 같은 any-to-any 모델이나 PCME 계열 확률 임베딩과의 직접 비교가 없음
  - 표준편차나 반복 실행이 없어 Table 5의 register 토큰 수(0개 39.21 대 4개 39.45)처럼 차이가 작은 비교는 해석이 어려움

- **본문과 식·표의 불일치**
  - 식 4는 로그와 음의 부호 없이 정답 쌍의 softmax 확률을 그대로 손실로 적어, 문자 그대로 최소화하면 정답 쌍의 확률을 낮추는 방향
  - 최종 손실 식은 모달리티별 손실에 이미 들어 있는 VIB 항을 한 번 더 더함
  - Table 14의 Average 행(58.66, 60.71, 68.73)이 Table 10의 Average 행과 똑같고, Table 14의 네 과제 값을 평균한 값과 맞지 않음
  - 검색이 모든 설정에서 앞선다고 서술하지만 Table 2의 소리→위성 R@1은 TaxaBind보다 낮고(2.24 대 2.36), 데이터 양 실험도 모든 설정에서 앞선다고 하지만 Table 4의 20% 위치→위성 검색은 TaxaBind보다 낮음(9.44 대 9.62)
  - 10% 데이터의 샘플 수가 본문은 7,931개, Table 4 캡션은 7,913개

- **MUST와 비교한 설계상의 위치**
  - [MUST](/paper-review/posts/2603.26071/)가 추론 가능한 공유 성분은 결정적으로 복원하고 고유 잔차만 생성한 것과 달리, ProM3E는 임베딩 전체를 하나의 가우시안에서 생성해 입력이 부족해서 생기는 불확실성과 모달리티 고유 정보에서 오는 불확실성을 나누지 않음
  - 고정된 정렬 임베딩을 타깃으로 latent에서 가려진 모달리티를 예측한다는 점은 JEPA와 닮았지만, 타깃 인코더를 함께 학습하지 않아 첫 단계 정렬의 품질과 modality gap이 복원의 상한이 됨

- **적용 범위**
  - 생태학의 여섯 모달리티와 전역 임베딩에만 적용했고, 학습 때 보이는 모달리티를 한두 개로 제한해 입력이 많을 때의 동작은 추론 결과로만 확인
  - 저자들도 인정하듯 iNaturalist 기반 데이터는 인구 밀집 지역과 일부 종에 편향되어, 위치 σ와 종 다양성의 상관도 관측 밀도의 영향을 받을 수 있음
