## Summary

DivPrune은 시각 토큰 pruning을 선택된 토큰 사이의 최소 거리를 최대화하는 Max-Min Diversity Problem(MMDP)으로 정식화하고, 그 해로 얻은 부분집합만 LLM에 넣는 학습 없는(training-free) 방법이다. 저자들은 LLaVA 1.5/1.6과 LLaVA-NeXT-Video의 16개 이미지·비디오 데이터셋에서 높은 pruning 비율에도 기존 방법보다 성능을 잘 유지한다고 보고한다.

- **기여 1. MMDP 기반 토큰 pruning 방법 DivPrune**
  - 선택 토큰의 다양성을 최대화해 중복을 줄인 대표 부분집합 구성

- **기여 2. 학습·캘리브레이션 없는 플러그인 방식**
  - fine-tuning이나 캘리브레이션 데이터 없이 기존 LMM에 적용

- **기여 3. 이미지·비디오 16개 데이터셋 평가**
  - pruning 비율 80% 이상의 극단적 압축에서 두드러진 성능 우위

- **기여 4. 실제 메모리·지연 시간 감소**
  - 대부분의 데이터셋에서 원본과 비슷한 정확도로 GPU 메모리와 추론 지연 감소

## Background

대형 멀티모달 모델(large multimodal model, LMM)은 텍스트와 이미지·비디오를 토큰으로 바꿔 하나의 LLM에 넣는다. 시각 토큰은 입력을 수천 개 단위로 늘리고, 연산 시간과 메모리는 입력 길이의 제곱에 비례해 커진다. 선행 연구는 시각 정보의 중복이 커서 시각 토큰을 50%에서 95%까지 줄여도 추론이 빨라질 수 있음을 보였고, 시각 토큰 일부만 남기는 pruning이 주요 해법이 되었다.

- **① 어텐션 점수 기반 pruning ([FastV](/paper-review/posts/2403.06764/), PruMerge)**
  - **방식**: 어텐션 점수로 덜 중요한 토큰을 제거. FastV는 LLM 앞쪽 층의 어텐션으로, PruMerge는 비전 인코더의 어텐션 희소성으로 토큰을 고르거나 병합
  - **한계**: 중요한 토큰 일부를 놓치고 비슷한 토큰을 함께 남기는 경향, 높은 압축률에서 고유 토큰이 부족해 fine-tuning 없이 성능 급락

- **② 캘리브레이션 기반 pruning (FitPrune, VTW)**
  - **방식**: 캘리브레이션 데이터에서 LLM 출력을 분석해 pruning 층이나 비율 결정. FitPrune은 pruning 전후 어텐션 분포 차이로 pruning 방식을 정하고, VTW는 고른 층 이후 시각 토큰을 모두 제거
  - **한계**: 모델마다 캘리브레이션이 필요한 비용과 번거로움

- **③ fine-tuning 기반 토큰 축소 (Matryoshka Multimodal Models, TokenPacker)**
  - **방식**: 여러 해상도의 중첩 토큰 표현을 학습하거나, 정보를 적은 토큰에 압축하는 projector를 대규모 데이터로 학습
  - **한계**: 학습에 큰 연산 자원이 필요해 적용 범위 제한

학습과 캘리브레이션이 필요 없는 것은 어텐션 기반 방법뿐이지만, 토큰마다 중요도를 따로 매겨 상위를 고르므로 비슷한 토큰이 함께 뽑히는 중복을 막지 못한다. 나머지 두 계열은 이를 모델별 캘리브레이션이나 추가 학습으로 보완한다. 저자들은 추가 학습과 캘리브레이션 없이 높은 pruning 비율에서도 원래 토큰 집합을 대표하는, 중복이 적은 부분집합을 고르는 방법이 필요하다고 제기한다.

## Method

DivPrune은 어떤 토큰이 중요한가라는 질문을, 남긴 토큰이 원래 집합을 얼마나 고르게 대표하는가로 바꾼다. 시각 토큰은 임베딩 공간에서 비슷한 패치끼리 여러 군집을 이루는데, 점수 상위만 남기면 점수가 높은 군집에서 거의 같은 토큰이 여럿 뽑히고 다른 군집은 통째로 빠질 수 있다. DivPrune은 부분집합 안에서 가장 가까운 두 토큰 사이의 거리가 가장 큰 부분집합을 고른다. 이 기준에서는 거의 같은 토큰 두 개를 함께 남기면 최소 거리가 곧바로 작아지므로 중복이 가장 큰 벌점이 되고, 선택된 토큰은 모든 군집에 흩어진다. 선택은 한 번에 하나씩 이뤄진다. 가장 가까운 이웃과도 가장 멀리 떨어진 토큰을 먼저 고르고, 이후 이미 뽑힌 토큰들과의 최소 거리가 가장 먼 후보를 목표 개수까지 추가한다. 이 과정은 projector를 거친 시각 토큰끼리의 거리만 쓰며, 텍스트나 어텐션을 보지 않고 LLM 입력 전에 끝난다.

이 구성은 Background의 한계에 각각 대응한다. 개별 토큰의 어텐션 점수 대신 선택 집합의 최소 거리를 목표로 삼아 중복을 직접 억제하고, 모든 군집에서 토큰을 확보해 높은 압축률에서도 대표성을 유지한다. 입력 토큰끼리의 거리만 쓰므로 캘리브레이션 데이터가 필요 없고, 가중치를 바꾸지 않아 fine-tuning 없이 어떤 LLM과 비전 인코더에도 붙일 수 있다. 저자들은 LLM 입력 전에 토큰을 줄이므로 KV caching 같은 추론 최적화와도 함께 쓸 수 있다고 설명한다.

### Large Multimodal Models (LMMs)

LMM은 텍스트 입력 $T$와 시각 입력 $V$의 쌍을 처리한다. 텍스트는 $N$개의 텍스트 토큰 $$E_t = \{t_1, \dots, t_N\}$$이, 시각 입력은 비전 인코더와 projector를 거쳐 $M$개(일반적으로 $M \gg N$)의 시각 토큰 $$E_v = \{v_1, \dots, v_M\}$$이 되고, LLM은 이를 합쳐 $\hat{N}$개의 출력 토큰을 자기회귀(auto-regressive) 방식으로 생성한다.

$$
P(y_1, \dots, y_{\hat{N}} \mid E_t, E_v) = \prod_{i=1}^{\hat{N}} P(y_i \mid y_{<i}, E_t, E_v)
$$

### Token Pruning

중복이 더 많은 시각 토큰을 pruning 대상으로 삼아, $E_v$를 크기 $\tilde{M}$($\tilde{M} < M$)인 부분집합 $\tilde{E}_v$로 보내는 사상 $f$ 중 pruning 전후 출력 차이를 최소화하는 것을 찾는다.

$$
\min_{f :\, E_v \to \tilde{E}_v} \mathcal{L}\left(\mathcal{P}, \tilde{\mathcal{P}}\right) \quad \text{subject to} \quad \lvert \tilde{E}_v \rvert = \tilde{M}
$$

여기서 $$\mathcal{P} = P(y_1, \dots, y_{\hat{N}} \mid E_t, E_v)$$, $$\tilde{\mathcal{P}} = P(y_1, \dots, y_{\hat{N}} \mid E_t, f(E_v))$$이고, $\mathcal{L}$은 두 출력의 차이를 재는 손실이다.

### DivPrune: Method Overview

저자들은 이 문제를 $\tilde{M}$개짜리 부분집합 $S$ 가운데 원소 사이 최소 거리가 가장 큰 집합을 찾는 MMDP로 다시 정식화하며, 거리로 코사인 거리를 쓴다.

$$
\begin{aligned}
\tilde{E}_v &= \arg\max_{S \subset E_v} \left[ \min_{\gamma, \omega \in S} d(\gamma, \omega) \right] \\
d(\gamma, \omega) &= 1 - \frac{\gamma \cdot \omega}{\lVert \gamma \rVert \lVert \omega \rVert}
\end{aligned}
$$

저자들은 LLaVA 1.5의 576개처럼 토큰 수가 제한적이고 기존 솔버는 GPU 가속을 고려하지 않으므로 정확한 해(exact solution)를 직접 구한다고 설명하며, 선택 오버헤드는 LLM 연산에 비해 무시할 만하다고 본다. Algorithm 1의 첫 단계는 가장 가까운 이웃까지의 거리가 최대인 토큰을 선택 집합으로 옮기고, 둘째 단계는 선택 집합과의 최소 거리가 최대인 후보를 $\tilde{M}$개가 될 때까지 옮긴다. 거리 행렬은 처음에 행렬 곱 한 번으로 구하며, 같은 절차를 LLM 중간 층의 시각 토큰 hidden state에 적용할 수도 있다.

## Limitations & Thoughts

- **"정확한 해"와 greedy 알고리즘의 간극**
  - Algorithm 1은 선택 집합과 가장 먼 토큰을 하나씩 더하는 greedy 절차로 farthest point sampling과 같은 구조이며, NP-hard인 MMDP의 최적해를 보장하지 않음
  - 따라서 "정확한 해", "가장 높은 다양성"은 greedy 근사의 결과로 읽어야 하고, Figure 3(b)는 DivPrune이 직접 최적화하는 값을 비교한 것이라 성능과의 연결 근거는 Table 4의 무작위·Min-Max 비교가 담당

- **FastV 대비 격차의 출처**
  - 부록의 FastV 설정(7B 기준 K=3, R=0.001)은 약 15% TFLOP을 맞추려 3번째 층 이후 시각 토큰을 거의 남기지 않는 설정으로 보이며, Table 1에서 FastV와 VTW 수치가 거의 같음
  - Table 4의 층 0 무작위 선택(MMB 52.66, POPE 72.78)도 Table 1의 FastV(20.62, 32.84)보다 훨씬 높아, 격차의 상당 부분은 중요도 대 다양성보다 pruning 시점과 남기는 양의 차이로 설명됨 (두 표의 TFLOP 표기가 달라 직접 비교에는 한계)
  - 다양성 기준 자체의 효과는 무작위 선택 대비 평균 5.68점(62.34 대 56.66)으로 보는 편이 정확

- **TFLOP 표기의 불일치**
  - 같은 성능값(MMB 59.19, MMMU 35.89, POPE 86.02, SQA 68.27)이 Table 1에서는 15.63%, Table 3·4에서는 19.61%로 표기
  - TFLOP 식의 어텐션 제곱항 부호가 FastV 원식과 달리 음수여서 오기인지 확인 필요

- **질문을 보지 않는 선택**
  - 시각 토큰끼리의 거리만 쓰므로 같은 이미지라면 질문이 달라도 같은 부분집합이 남음
  - 질문 관련 영역이 작은 TextVQA에서 원본(46.08) 대비 하락이 크고(35.97) PruMerge(37.70)보다 낮은 점이 이 한계와 맞닿음
  - CDPruner(NeurIPS 2025)는 조건부 다양성으로, MMTok(ICLR 2026)은 텍스트와 시각 토큰을 함께 덮는 커버리지로 질문 조건을 더함

- **효율 측정의 범위**
  - 효율은 한 모델과 VideoChatGPT 499개 샘플에서만 측정했고, 기준선이 디코딩마다 pruning을 반복한다는 설명은 구현의 특성 ([FastV](/paper-review/posts/2403.06764/)는 원리상 입력 처리 때 한 번 제거)
  - 거리 행렬이 토큰 수의 제곱에 비례해, 긴 비디오나 고해상도 입력에서의 선택 비용은 별도 확인 필요

- **계보 속 의의**
  - pruning의 질문을 개별 토큰의 중요도에서 부분집합의 대표성으로 옮긴 커버리지 계열의 출발점
  - greedy max-min 선택은 k-center의 greedy 풀이와 같은 형태여서, EVTP-IVS는 k-center에 공간 정보를, SCoRe는 salience를 결합한 weighted k-center로, SCOPE는 saliency와 coverage의 결합으로 확장
