## Summary

PathAgent는 병리 전체 슬라이드 이미지(whole-slide image, WSI)에 대한 질문에 답하는 training-free 에이전트(agent)다. 검색 모델 PLIP, 병리 시각-언어 모델(vision-language model, VLM) Patho-R1, 대규모 언어 모델(large language model, LLM) Qwen3-4B를 조합해 영역 검색, 형태 묘사, 증거 충분성 판단을 반복하고 그 과정을 텍스트로 남긴다.

- **기여 1. training-free 대화형 WSI 에이전트**
  - 기성 병리 모델의 조율만으로 동작하는 첫 WSI 에이전트, 병리의가 모든 단계에 개입 가능한 구조

- **기여 2. 다단계 추론(Multi-Step Reasoning)**
  - 답 추정, 자기 성찰, 부족 정보 탐색으로 나눈 단계적 판단과 다음 검색 질의의 자체 생성

- **기여 3. 적응적 배율 선택과 증거 검색 개선**
  - 분석 상태에 따른 확대 배율 선택, 단순화한 Navigator 질의 전략을 통한 증거 포착 정확도 향상

## Background

WSI는 한 변이 최대 100k 픽셀이라 모델에 통째로 입력할 수 없다. 병리의는 저배율로 훑어 관심 영역(region of interest, RoI)을 고르고, 질문에 맞춰 배율을 올려 증거를 모으다가 충분하면 결론을 낸다. 저자들은 기존 단일 모델이 이 반복 과정을 담지 못해 예측 근거를 추적할 수 없다고 지적한다.

- **① CLIP 계열 검색 모델 (PLIP, CONCH, CPath-CLIP)**
  - **방식**: 이미지·텍스트 임베딩(embedding) 유사도 기반 패치 검색
  - **한계**: 고정 캡션 템플릿에 묶인 확장성, 추론 생성 불가
  - **PathAgent의 대응**: PLIP은 RoI 선택에만 사용, 질의는 Executor가 매 라운드 작성

- **② 패치·썸네일 VLM (Quilt-LLaVA, Patho-R1)**
  - **방식**: 이미지에 대한 자유 형식 설명 생성
  - **한계**: context window 한계로 썸네일이나 일부 패치만 입력, 전체 맥락 손실
  - **PathAgent의 대응**: 선택 패치만 VLM이 묘사하고 LLM이 텍스트로 종합

- **③ 슬라이드 인코더 + LLM (SlideChat, WSI-LLaVA, TITAN)**
  - **방식**: 슬라이드 인코더(encoder) 출력을 LLM에 입력
  - **한계**: 답의 근거 영역 추적 불가
  - **PathAgent의 대응**: 라운드마다 (배율, 좌표, 묘사) 기록

- **④ 병리 에이전트 (SlideSeek, CPathAgent 등)**
  - **방식**: LLM과 외부 도구의 결합
  - **한계**: 비싼 큐레이션(curated) 학습 데이터 의존, 대부분 코드 비공개
  - **PathAgent의 대응**: 추가 학습 없는 조율, 코드 공개

## Method

PathAgent는 세 모듈로 구성된다. Navigator는 분석할 영역을 선택하고, Perceptor는 선택된 패치의 형태학적 특징을 묘사하며, Executor는 이 묘사를 바탕으로 판단과 다음 행동을 결정한다. Executor(LLM)는 이미지를 직접 입력받지 않으며, Perceptor가 생성한 묘사 문장과 패치의 좌표·배율만을 근거로 추론한다(Figure 3). 각 라운드에서 Executor는 답을 추정하고 근거의 충분성을 판정한 뒤, 다른 영역에서 근거를 더 찾는 Action 1(추가 탐색), 선택 영역을 확대하는 Action 2(확대), 답을 확정하는 Action 3(결론) 중 하나를 선택한다. Action 1은 탐색 루프로 돌아가는 반면, Action 2는 확대를 한 번 수행한 뒤 곧바로 결론 단계로 이어진다(Algorithm 1).

![PathAgent 전체 구조](/assets/img/posts/2511.17052/fig2-overview.webp)
_Figure 2. PathAgent 전체 구조_

초기 분석 상태는 다음과 같이 구성된다. 슬라이드를 5× 패치 $N$개로 분할하고, Navigator가 질문 $q$와 각 패치의 관련도 점수(relevance score) $r_i^1$을 계산해 상위 $k_1$개를 선택한다. 선택된 패치의 (배율, 좌표, 묘사) 집합이 초기 상태 $S_1$이 된다.

$$
X_1 = \{x_i \mid i \in \mathrm{Top}_{k_1}(\{r_i^1\}_{i=1}^{N})\}
$$

### Exploring for Additional Evidence

근거가 부족하고 확대로는 해결되지 않는다고 판단되면, Executor는 부족한 정보를 새 질의 $I_t$로 기술하고 Navigator는 아직 선택되지 않은 패치 중 상위 $k_t$개를 선택한다.

$$
X_{t+1} = \{x_i \mid i \in \mathrm{Top}_{k_t}(\{r_i^t\}_{x_i \in X \setminus \bigcup_{k=1}^{t} X_k})\}
$$

예를 들어 $N=20$이면 $k_1=\lceil 0.1N \rceil=2$, $k_t=\lceil 0.05N \rceil=1$이다. 아래 표의 관련도는 설명을 위해 가정한 값이다.

| 패치 | 1라운드 (질문 $q$) | 2라운드 (새 질의 $I_1$) |
|---|---|---|
| P1 | **0.31** → 선택 | 0.35 → 기선택, 제외 |
| P2 | **0.28** → 선택 | 0.10 → 기선택, 제외 |
| P3 | 0.12 | 0.30 |
| P4 | 0.25 | **0.33** → 선택 |

2라운드에서 P1의 관련도가 가장 높지만 이미 선택된 패치이므로 제외되고, P4가 새로운 근거로 추가된다.

### Zooming in for Finer Details

확대가 필요하다고 판단되면 선택 영역을 Executor가 지정한 배율로 확대해 겹치지 않는 하위 패치로 분할하고, Navigator가 질문과 관련된 하위 패치만 골라 그 묘사를 상태에 추가한다. 이후 Executor는 모든 라운드의 상태를 종합해 최종 답과 추론 사슬(chain-of-thought)을 출력한다. 최대 라운드 수는 5이며, Navigator, Perceptor, Executor로 각각 PLIP, Patho-R1, Qwen3-4B를 사용한다.

- **슬라이드 모델과 범용 VLM 대비 우위**
  - 세 데이터셋 전반에서 가장 좋은 성능
  - 범용 VLM은 WSI 전체를 처리하지 못하고 세밀한 형태 정보가 없어 등급·아형 과제에서 불리, PathAgent는 자동 RoI 검색으로 이를 극복한다는 설명

- **두 핵심 모듈의 필요성**
  - 어느 모듈이 빠져도 정확도 하락과 반복 증가, 둘 다 쓸 때 최고 성능
  - Navigator는 반복을 크게 줄이지만 단독으로는 정확도 개선 여지 존재
  - 패치를 많이 넣을수록 좋은 것이 아니라 중복 정보가 방해한다는 결과 (Figure 4)

## Limitations & Thoughts

- **질문 유사도 기반 검색의 한계**
  - 질문과 패치의 PLIP 유사도로 영역을 고르므로, 시각적 대응이 약한 속성에 취약할 가능성. HER2 발현은 원래 면역조직화학(immunohistochemistry, IHC)으로 판정하는 지표라 모든 모델이 낮음(Table 1)
  - 이 한계를 다룬 후속 연구: PathNavigate(슬라이드 자체의 특이 영역 우선), BEACON(가설 구분에 유리한 증거 선택), AdaptivePath(같은 1저자, 학습된 Navigator)

- **과대평가되기 쉬운 반복 추론**
  - 저자는 병리의식 반복 추론을 강조하지만, 평균 반복은 2회 미만(Table 3, Figure 6)이고 확대는 1회로 끝나는 구조
  - Table 3에서 Navigator 기여가 더 커, 성능은 첫 라운드 검색 품질에 좌우될 가능성

- **실험 결과에 대한 평가**
  - 전체 1위지만 전용 모델과의 격차가 작고 종양 유형·수용체 상태는 SlideChat 우세. "넘는다"보다 "학습 없이 대등하다"에 가까운 결과
  - 가장 큰 격차는 세포 수준 단서가 필요한 조직학적 등급으로 설계 의도와 부합
  - VLM 기준선은 축소·다수결 입력 전략의 한계가 섞인 비교
  - 같은 Quilt-LLaVA도 구조 안에서 더 높아(Table 1, 2) 구조의 기여를 시사하나, 조건이 달라 통제 비교는 아님

- **보고의 빈칸**
  - 추론 시간 미보고, 서술형 답변은 단어 겹침 지표(BLEU·METEOR)로만 평가, Patho-R1 단독 기준선 부재
  - 같은 설정의 BCNB 전체 정확도가 Table 1과 Table 3에서 다른 값 (논문 확인 필요, 오기로 추정)

- **지금 시점의 의의**
  - 전용 모델 학습 없이 기성 부품 조합으로 경쟁력 있는 성능과 추적 가능한 근거를 얻을 수 있다는 기준점
  - 부품 교체형 구조라 병리 파운데이션 모델(foundation model)의 발전을 흡수할 수 있는 설계
